# Triple Try – Number Guessing Game

A simple Python-based number guessing game where players get three attempts to guess a randomly generated number.

### Features
- Three difficulty levels: Easy (1–10), Medium (1–50) and Hard (1–100).
- Random number generation.
- Hints to guide players after incorrect guesses.
- Limited to three attempts.

### Concepts Used
Python functions

Conditional statements

For loops

Random module

User input and output
